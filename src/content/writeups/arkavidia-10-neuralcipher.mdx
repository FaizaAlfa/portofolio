## 2. Mathematical Modeling & Analysis

Decompressing and inspecting `chall.pyc` reveals that the transformation is a classic **Linear Transformation Cipher** disguised as a neural network dense layer without non-linear activation:

```text
y = (W · x) mod p
```

Where:
- `x` is the flag vector (input characters as ASCII byte values, length 52).
- `W` is the weight matrix of dimensions 52 x 52.
- `y` is the given output vector of length 52.
- `p` is the modular base (256).

Because the output numbers fall within the range [0, 255], and since the determinant `det(W) mod 256` is coprime to 256 (an odd integer), the weight matrix `W` is strictly invertible in the ring Z/256Z.

Therefore, we can invert the cipher directly:

```text
x = (W^-1 · y) mod 256
```

## 3. Exploit / Solver Script

We implement Gauss-Jordan elimination with modular arithmetic over modulo 256:

```python
import numpy as np

# 1. Load weights matrix (52x52)
with open('weights', 'rb') as f:
    f.read(128)  # Skip standard NumPy header
    weights = np.frombuffer(f.read(), dtype=np.int32).reshape(52, 52)

# 2. Load output vector (52 elements)
with open('output', 'r') as f:
    output = np.array([int(line.strip()) for line in f if line.strip()])

def mod_inv_matrix(matrix: np.ndarray, mod: int) -> np.ndarray:
    n = matrix.shape[0]
    augmented = np.hstack([matrix % mod, np.eye(n, dtype=np.int64)])

    for i in range(n):
        # Find pivot
        pivot = -1
        for j in range(i, n):
            if augmented[j, i] % 2 != 0:  # Must be odd for modular inverse mod 256
                pivot = j
                break
        if pivot == -1:
            raise ValueError(f"Matrix is not invertible mod {mod}")

        # Swap rows
        augmented[[i, pivot]] = augmented[[pivot, i]]

        # Normalize with modular inverse
        inv = pow(int(augmented[i, i]), -1, mod)
        augmented[i] = (augmented[i] * inv) % mod

        # Gauss-Jordan elimination
        for j in range(n):
            if j != i:
                factor = augmented[j, i]
                augmented[j] = (augmented[j] - factor * augmented[i]) % mod

    return augmented[:, n:] % mod

# 3. Decrypt the Flag
mod = 256
W_inv = mod_inv_matrix(weights, mod)
input_vec = np.dot(W_inv, output) % mod
flag = ''.join([chr(int(x)) for x in input_vec])

print(f"[+] Recovered Flag: {flag}")
```
