## 1. Ringkasan Tantangan

Jelaskan deskripsi tantangan, file yang diberikan (binary, PCAP, memory dump, dll), dan tujuan yang ingin dicapai.

```bash
# Contoh perintah triage awal
$ file challenge_bin
$ checksec --file=challenge_bin
```

## 2. Analisis Statis & Dinamis

Tuliskan langkah-langkah investigasi teknis di sini. Anda dapat menyisipkan potongan kode C, Assembly, atau Python solver.

```c
// Contoh potongan kode dekompilasi
int validate_key(char *input) {
    if (strcmp(input, "secret_key") == 0) {
        return 1;
    }
    return 0;
}
```

<Callout type="tip" title="Catatan Analisis">
Tambahkan catatan penting atau teknik bypass yang digunakan saat analisis di sini.
</Callout>

## 3. Exploit / Solver Script

Tuliskan kode solver otomatis yang Anda gunakan untuk menyelesaikan tantangan ini:

```python
#!/usr/bin/env python3
# Solver script
def solve():
    print("[+] Recovering flag...")

if __name__ == "__main__":
    solve()
```
