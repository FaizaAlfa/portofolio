## 2. Crypto: `The Tiny Exponent Incident` (Hastad's Broadcast Attack)

### Vulnerability Analysis
The challenge supplies 3 RSA ciphertexts (`c1, c2, c3`) corresponding to 3 distinct moduli (`n1, n2, n3`) with the same public exponent `e = 3`.

According to **Hastad's Broadcast Theorem**, by applying the **Chinese Remainder Theorem (CRT)** across pairwise coprime moduli `n1, n2, n3`, we can solve for:

```text
C = m^3 mod (n1 * n2 * n3)
```

Since `m < n_i` for all `i`, `m^3 < n1 * n2 * n3`, allowing us to extract the integer cube root of `C` directly over integers Z without modular reduction.

### Python Solver with gmpy2
```python
import gmpy2
from Crypto.Util.number import long_to_bytes
from functools import reduce

e = 3
c_list = [c1, c2, c3]
n_list = [n1, n2, n3]

def chinese_remainder_theorem(c, n):
    prod = reduce(lambda a, b: a * b, n)
    total = 0
    for c_i, n_i in zip(c, n):
        p = prod // n_i
        total += c_i * int(gmpy2.invert(p, n_i)) * p
    return total % prod

crt_val = chinese_remainder_theorem(c_list, n_list)
m, exact = gmpy2.iroot(crt_val, e)

if exact:
    flag = long_to_bytes(int(m)).decode()
    print(f"[+] Recovered Flag: {flag}")
```
